Instalação e privacidade

Extraia o ZIP do seu navegador para uma pasta permanente. Abra opera://extensions ou chrome://extensions, ative o modo de desenvolvedor, escolha Carregar sem compactação e selecione a pasta com manifest.json. A configuração abre automaticamente.

Escolha OpenRouter ou OpenAI, cole sua chave de API e o ID de um modelo compatível com Chat Completions. Leia o consentimento e clique em Salvar. Autorize o acesso apenas ao provedor escolhido. Abra um vídeo no YouTube e use o ícone b4Play; se desejar, ative o hover.

Não há Node.js, servidor local ou token adicional. A chave fica na sessão até encerrar o navegador. Se escolher Lembrar, ela fica sem criptografia no armazenamento local da extensão. Nenhuma chave fica no código distribuído.

O link do vídeo é enviado ao Tactiq em uma aba temporária. O título e a transcrição são enviados por HTTPS ao provedor escolhido; no OpenRouter há também os provedores de modelos envolvidos no roteamento. Suas políticas de retenção se aplicam. O pedido usa store:false; isso não garante retenção zero. A API pode cobrar, incluindo resumos automáticos e seções de vídeos longos.

Os resumos ficam na sessão (até 30 vídeos, reutilização por 24 horas). A transcrição não é gravada pela extensão; existe temporariamente durante o processamento. Apagar configuração remove chave, preferências e resumos e revoga o acesso aos provedores. Uma chamada já enviada pode ter sido processada e cobrada. Desinstalar a extensão também remove seus dados locais.

O Tactiq pode falhar, exigir verificação ou não suportar o vídeo/idioma. Não contornamos essas restrições. Use a importação .txt nesse caso. Shorts e eventos apenas visuais não são analisados. Resumos podem conter erros.

A versão anterior 0.3.0 foi detectada pelo Defender. Esta reconstrução não tem certificação de segurança nem aprovação de loja. Se houver alerta, mantenha o bloqueio e envie o pacote à Microsoft para análise. Não desative o antivírus.

Install and privacy

Extract your browser ZIP to a permanent folder. Open opera://extensions or chrome://extensions, enable Developer mode, choose Load unpacked and select the folder containing manifest.json. Settings open automatically.

Select OpenRouter or OpenAI, paste your own API key and a Chat Completions compatible model ID, read the consent and click Save. Allow access to your selected provider. Open a YouTube video and use the b4Play icon; optionally enable hover.

No Node.js, local server or extra token. The key lasts for the browser session by default. Remember stores it unencrypted in the extension's local storage. Distributed code contains no user keys.

The video URL goes to Tactiq in a temporary tab. The title and transcript go over HTTPS to your selected AI provider; OpenRouter also involves its routed model providers. Their retention policies apply. Requests use store:false; this does not guarantee zero retention. API usage can cost money, including automatic summaries and sections of long videos.

Summaries remain in session storage (up to 30 videos, 24-hour reuse). The extension does not persist transcripts; they exist temporarily during processing. Delete settings removes keys, preferences and summaries and revokes provider access. A request already sent may have been processed and billed. Uninstalling also removes local extension data.

Tactiq can fail, request verification or not support a video/language. These restrictions are not bypassed. Import .txt in that case. Shorts and visual-only events are not analyzed. Summaries can contain errors.

Defender flagged the previous 0.3.0 version. This rebuild is not security-certified or store-approved. If flagged, keep it blocked and submit the package to Microsoft. Do not disable antivirus.
